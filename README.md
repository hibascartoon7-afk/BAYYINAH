# بيِّنة — لا حكم بلا بيّنة

أداة ذكاء اصطناعي تعين المعرّفين بالإسلام على التحقق من الأحاديث المنتشرة قبل نشرها.
تستقبل الرسالة كما تصل، فتعيد كل حديث إلى مصدره المعتمد، وتعرض أقوال العلماء منقولة من كتبهم كما هي،
أو تمتنع صراحة وتحيل إلى مختص حين لا تجد أصلًا.

**المسار:** الرابع — أدوات المعرفة والتحقق لتمكين المعرّفين بالإسلام
**تحدي الذكاء الاصطناعي في خدمة المحتوى الإسلامي — مؤسسة باذل، 2026**

---

## المبدأ الحاكم

> النموذج اللغوي لا يكتب حكمًا ولا مصدرًا ولا رقم حديث أبدًا.
> كل حكم وكل مصدر يُنقل من البيانات كما هو، منسوبًا إلى قائله وكتابه.

---

## ما تفعله الأداة

| الحالة | ما يراه المستخدم |
|---|---|
| وُجد النص بلفظه | المتن، ومصدره وموضعه، وأقوال العلماء بنصوصها، وفروق اللفظ |
| وُجد قريب في المعنى فقط | أحاديث أخرى قريبة، مع تصريح بأنها **ليست حكمًا** على ما كتبه |
| سؤال فتوى شخصية | لا تُفتي، وتحيل إلى جهة إفتاء معتمدة |
| سؤال عام، أو آية قرآنية، أو نص غير عربي | توضّح وظيفة الأداة، ولا تعرض أحاديث عشوائية جوابًا |
| رسالة كاملة بتحيتها وعبارات نشرها | تستخرج الحديث منها، وتنبّه إن بقي فيها كلام لم تجده في مصادرها |
| لم يُعثر عليه | امتناع صريح وإحالة إلى مختص |

## التشغيل

```bash
git clone https://github.com/hibascartoon7-afk/BAYYINAH.git
cd BAYYINAH
python -m venv .venv
.venv\Scripts\activate          # ويندوز
# source .venv/bin/activate     # ماك ولينكس
pip install -r requirements.txt
python engine.py                # أول تشغيل يبني الفهرس، ثم يصير سريعًا
```

**النموذج اللغوي (اختياري):** أنشئ ملف `.env` فيه:

```
GEMINI_API_KEY=مفتاحك
```

وبدونه تعمل الأداة كاملة بجمل تمهيدية جاهزة، لأن الأحكام والمصادر لا تعتمد على النموذج أصلًا.

**إعادة بناء الفهرس** بعد أي تعديل في البيانات أو في `normalize.py` تحدث تلقائيًا، ويمكن فرضها:

```bash
python engine.py --rebuild
```

## هيكل المستودع

```
├── engine.py            المحرك: الفهرسة، والبحث، وفحص جودة النص، وبناء النتيجة
├── normalize.py         توحيد النص العربي (يُطبَّق على البيانات وعلى سؤال المستخدم)
├── llm.py               ربط النموذج اللغوي بحمايات الخط الأحمر
├── system_prompt.py     التعليمات الثابتة للنموذج
├── scope.py             كشف ما يقع خارج وظيفة الأداة: السؤال العام، والآية، والنص غير العربي
├── message.py           التحقق من الرسالة كاملة كما تصل، والتنبيه على الكلام المُلحق بالحديث
├── clean.py             تنظيف البيانات الخام، مع سجل لكل تعديل
├── app.py               واجهة المستخدم (Streamlit)
├── ocr.py               قراءة النص من الصور
├── data/
│   ├── hadith_database.json     الصحيحان بعد التنظيف
│   ├── rulings_database.json    كتب الأحكام بعد التنظيف
│   └── log.json                 سجل التنظيف: كل حذف وتعديل وسببه
├── evaluation/
│   ├── test_set.csv              مجموعة الاختبار: 50 رسالة، منها 12 حالة رسمية و11 رسالة كاملة كما تصل
│   ├── run_eval.py               قياس الأداة على مجموعة الاختبار
│   ├── compare_general_model.py  المقارنة بنموذج لغوي عام
│   ├── results.csv               نتيجة كل رسالة
│   └── summary.md                ملخص القياس
└── docs/
    ├── METHODOLOGY.md   المنهجية العلمية
    ├── ARCHITECTURE.md  البنية التقنية
    ├── SOURCES.md       المصادر والأدوات والتراخيص
    └── EVALUATION.md    الاختبار والقياس
```
